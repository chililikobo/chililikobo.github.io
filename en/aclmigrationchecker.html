Product Overview

"High-speed, high-precision access rights verification for reliable data migration."

ACL Migration Checker is a dedicated auditing utility that verifies whether access control lists (ACLs) match accurately between source and destination storage during file server and NAS migrations. It provides robust verification not only in Active Directory environments but also in Workgroup scenarios where migrating SIDs is difficult and permissions must be reconfigured.

High-Speed Scanning & Snapshots

Rapidly scans local drives and network shares using the optimal mode displayed on a 4-tier header speed badge (ultra-fast on local NTFS as Admin). Saves compact .json.gz snapshots for offline comparison.

Flexible Comparison (Workgroup & AD)

Accurately detects permission differences (including Deny rules) even when hostnames, IPs, or top-level folder names change—including Workgroup local account matching, deep paths (>260 chars), and junctions.

Three Views & Side-by-Side ACL Details

Switch between synchronized Tree View (diff filter & Prev/Next jump), Diff List (status filters, search, Open Folder), and Error Log, while comparing exact permissions side by side in the bottom pane.

Themes, Live Language Switch & CSV Export

Switch Light/Dark themes and English/Japanese live from the header without restarting. Export diff results and error logs as Excel-ready CSV files for audit evidence.

How to Use

01

Scan or Load Source

Enter or drop a folder or share path (\\server\share) into Source Data and click Scan. Save as .json.gz for offline use.

02

Specify Destination & Compare

Enter the destination path (or load a saved .json.gz snapshot) into Destination Data and click Run Comparison.

03

Review & Export CSV

Switch between Tree View, Diff List, and Error Log to inspect discrepancies and export results as CSV.

Offline comparison ready: Carry .json.gz snapshots between isolated servers with no direct network route required.
