ACL Migration Checker is designed to be portable, allowing you to carry it on a USB flash drive or other removable media.

It requires no additional installations such as the .NET runtime. Simply place the downloaded folder anywhere, and you can immediately launch and use it on various PCs. To uninstall, just delete the entire folder.

Product Overview

"An access rights verification tool for reliable data migration."

ACL Migration Checker is a dedicated tool to verify if there are any differences in access control lists (ACLs) between the source and destination during data migrations for file servers or storage servers.

It is highly effective not only for migrations in Active Directory environments but also for verifying the reconfiguration and reassignment of permissions in Workgroup environments where migrating SIDs (Security Identifiers) is difficult.

Key Features

  • Scan and Save ACLs: Retrieves ACL information set on source and destination folders/files and saves it in a lightweight JSON.GZ format.
  • Compare Before and After Migration: Matches the two saved datasets to automatically detect and list missing permissions, excessive privileges, and mismatched accounts.
  • CSV Export: Output comparison results in CSV format. Ideal for creating post-migration reports or checklists for corrections.
  • Multilingual Support (EN/JA): Automatically switches the interface language based on your OS language settings, ensuring smooth operation across various environments.
