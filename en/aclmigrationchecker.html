Product Overview

"Access rights verification for reliable data migration."

ACL Migration Checker is a dedicated auditing utility that verifies whether access control lists (ACLs) match perfectly between source and destination storage during file server migrations. It provides robust verification not only in Active Directory environments but also in Workgroup scenarios where migrating SIDs is difficult and permissions must be manually reconfigured.

Scan and Save ACLs

Harvests complete ACL metadata from source and destination folders/files and saves it into lightweight, compressed JSON.GZ files.

Automated Difference Comparison

Cross-examines the two datasets to automatically detect missing permissions, excessive privileges, and mismatched accounts or groups.

CSV Export for Audit Reports

Export comparison results to CSV format. Perfect for creating post-migration audit evidence or remediation punch-lists.

Bilingual Interface (EN/JA)

Automatically selects English or Japanese based on the host OS language setting for seamless global operations.
