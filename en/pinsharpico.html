Product Overview

"From 256px to 16px. Relentlessly engineered for micro-dot clarity."

PinSharp ICO is a specialized Windows icon utility designed to solve common downscaling problems: white borders turning muddy gray, dark narrow slits vanishing, and sharp contours blurring away into vague shapes at small sizes like 16×16 or 24×24.

Downscaling a 256×256px original image down to 16×16px represents an extreme 1/256 area reduction. PinSharp ICO preserves high contrast for delicate borders, typography, and narrow gaps, generating multi-resolution Windows ICO files that stand out crisply on taskbars, title bars, and File Explorer.

Using the Command Line (CLI) Pro Edition

Run automated headless batch conversions directly from Command Prompt, PowerShell, or local build scripts without opening the GUI.

Note: Cloud-hosted ephemeral CI/CD environments (such as GitHub Actions runners) are not supported due to machine-bound license activation. Please use on local development machines or dedicated build PCs.

Syntax

PinSharpICO.exe <image-or-folder-path(s)...> [options]

Common Options

Option Description
-o, --output <path> Output destination folder (or .ico file path for single image)
--subfolder Automatically save into an icons/ subfolder next to source images
-c, --shape <shape> Shape mask: square, rounded, or circle
-s, --sizes <sizes> Comma-separated sizes (e.g., 16,32,48,256)
-h, --help Display command-line help information

Examples

# 1. Simplest conversion (saves .ico next to source image)
PinSharpICO.exe "app_icon.png"

# 2. Convert image with modern rounded corners
PinSharpICO.exe "photo.jpg" --shape rounded

# 3. Convert image with circular mask
PinSharpICO.exe "avatar.webp" --shape circle

# 4. Batch-convert an entire folder with rounded corners to an output directory
PinSharpICO.exe "D:\Assets\Images" -o "D:\Assets\Icons" --shape rounded

# 5. Automatically save into an 'icons/' subfolder
PinSharpICO.exe "D:\Assets\Images" --subfolder

# 6. Generate only specific sizes
PinSharpICO.exe "icon.png" -s 16,32,48,256
