Product Description

"Zero commands. Just launch to aggregate deep PC insights instantly."

Ohnuki-san Plus is a comprehensive Windows system information extractor and diagnostic utility built to streamline IT inventory auditing and device provisioning (kitting) workflows. Requiring zero installation and leaving zero registry traces, simply running the executable automatically harvests detailed hardware specifications, OS configuration, update history, Active Directory membership, proxy settings, and PnP devices, rendering everything into a clean HTML and Markdown report in seconds.

Reliable Identification

Accurately extract BIOS serial numbers, chassis IDs, UUIDs, and motherboard details. Eliminate human typos and keep IT asset registers 100% accurate.

Responsive & Lightweight UI

Starts analyzing instantly upon launch and renders reports in your default browser. High-speed native performance keeps field technicians moving fast.

Engineered for IT Operations

No complicated setup. Directly inspect enterprise proxy settings, static routes, Windows services status, and Entra ID / AD domain join parameters.

Slave Mode (Multi-Device & Offline Operations)

Ohnuki-san Plus features a built-in "Slave Mode" designed for flexible field operations. With a single license, you can authenticate once on an internet-connected Master machine, then copy the folder to run diagnostics on air-gapped target machines without internet access.

Usage Limit & Periodic Refresh
Continuous offline use on Slave devices is valid for up to 30 days. When the period expires, simply copy the authenticated folder from your Master machine again to reset the 30-day timer.
Step 1 Connect Master PC online and activate
Step 2 Copy the entire activated folder to USB
Step 3 Run on target offline PCs directly
