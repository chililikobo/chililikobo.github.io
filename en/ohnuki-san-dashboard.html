Ohnuki-san Lite or Ohnuki-san Plus is Required

Ohnuki-san Dashboard is a dedicated visual analyzer designed to ingest and parse report folders exported by Ohnuki-san Lite or Ohnuki-san Plus. Because this dashboard does not extract device information directly on its own, please generate your diagnosis reports with either tool first.

Product Description

"Turning massive reports into instant graphical insights."

Ohnuki-san Dashboard aggregates diagnostic reports collected across multiple workstations, offering an intuitive birds-eye view of your IT fleet's hardware configurations and OS distribution. Simply select a folder containing diagnostic reports, and Dashboard automatically analyzes and graphs version proportions, CPU/RAM configurations, and installed applications.

Intuitive Visual Insights

Understand hardware distributions and OS build breakdowns at a glance with interactive pie charts and tree views.

Batch Folder Ingestion

Select any directory containing multiple reports to process, aggregate, and visualize everything in one step.

100% Local & Secure

Zero cloud upload or external network dependencies. All data aggregation is performed entirely locally on your machine.

Lightweight & Portable

No complex database setups, Docker containers, or web servers required. Runs instantly from a single standalone binary.
