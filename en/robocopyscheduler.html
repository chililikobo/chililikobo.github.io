Product Overview

"The full power of Robocopy, made simple with an intuitive GUI and scheduling."

Robocopy Scheduler is an intuitive GUI frontend and scheduler management tool for Windows Robocopy. Without memorizing complicated command-line parameters, you can easily configure mirror syncs (/MIR), multithreading (/MT), and SMB compression (/COMPRESS) right within an elegant interface to run automated background backups seamlessly.

Intuitive GUI & Advanced Options

Configure mirror sync (/MIR), safe copy (/E), update-only (/E /XO), SMB compression (/COMPRESS), and backup mode (/ZB) with single-click ease.

Flexible Scheduling

Schedule backups hourly, daily, weekly, monthly, or with standard Cron expressions to run reliably in the background.

Sleep Prevention & System Tray

Built-in option to prevent unexpected PC sleep while waiting for backups. Supports silent auto-start in the system tray on Windows boot.

External Webhooks & CSV Logs

Automatically send backup notifications to Slack Webhooks or ntfy.sh. Includes real-time log viewer and CSV export functionality.

Live Action Demo

Live action: Set source & destination paths in GUI, and trigger backups with real-time log monitoring.

Main Use Cases

Periodic syncs for large datasets, NAS, & file servers
Fast multi-threaded & SMB-compressed site-to-site transfers
System-level backups bypassing permission access errors (/ZB)
Unobtrusive background automated sync schedules
