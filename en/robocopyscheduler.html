Product Overview

"Powerful Robocopy features made visual, automated, and effortless."

Robocopy Scheduler is an intuitive GUI frontend and scheduling management tool designed to automate and simplify Windows standard "Robocopy" command tasks. Without memorizing complex command-line arguments or writing batch scripts, you can easily configure advanced file transfer settings and run automated background backups.

Intuitive GUI & Advanced Options

Easily configure backup modes such as Mirror (/MIR), Safe Add (/E), or Update (/E /XO), as well as multi-threading, SMB compression (/COMPRESS), and bypassing access denial (/ZB) with just a few clicks.

Flexible Automated Scheduling

Supports Daily, Hourly, Weekly, Monthly, and advanced Custom (Cron) schedule expressions for reliable background execution.

Sleep Prevention & System Tray Residency

Blocks system sleep while waiting for schedules and supports background startup on Windows boot.

Multi-Channel Notifications & Log CSV Export

Automatically sends backup results to Slack Webhook or ntfy.sh. Displays execution history and error details in real-time with CSV export capability.

Main Use Cases

Scheduled synchronization for large data, NAS, and file servers
High-speed inter-site transfers using SMB compression and multi-threading
System backups requiring access right preservation and bypassing access denial
Unobtrusive background scheduling and automation without command windows

Frequently Asked Questions (FAQ)

Q. Why does Windows SmartScreen show "Windows protected your PC" when launching?

A. Yes, the application is 100% safe and clean. Because Robocopy Scheduler is an indie utility without an expensive EV digital signature, Windows SmartScreen may display a standard blue warning popup on first launch.
To launch the app, simply click "More info" on the popup window, then click the "Run anyway" button.

Q. Why use Robocopy Scheduler instead of standard Windows Task Scheduler with batch files?

A. Writing batch scripts with complex Robocopy parameters (/MIR, /ZB, /MT, etc.) can be difficult to manage and debug. Robocopy Scheduler provides a clean GUI with interactive parameter builders, built-in sleep prevention, real-time log viewers, CSV exports, and instant Slack/ntfy notifications without maintaining batch files.

Q. I cannot select automatic scheduled execution in a corporate environment (only manual is available).

A. To use the scheduled automatic execution feature in corporate environments such as domain-joined PCs or Entra ID (Azure AD) environments, a Pro Edition subscription (license activation) is required.
However, you can still use the "Run Now" button for manual backups without restriction even in the Free Edition.

Q. Is it necessary to install additional frameworks like .NET Runtime?

A. No, it is not required.
This application is a portable app compiled as a standalone executable using .NET 10 (Native AOT). It runs standalone without requiring any external runtime installations. It also does not use the Windows Registry.

Q. Will the PC go to sleep while waiting for a backup and skip the execution?

A. You can prevent unintended sleep while waiting for a backup by enabling "Block PC from going to sleep while waiting for schedules" in the "General Settings" tab.

Q. What is the criteria for error judgment based on the Robocopy Exit Code recorded in the log?

A. The Robocopy exit code is a bitmask. This application treats "0 to 7" as Successful (including normal file copies, no changes, and warnings like extra files in the destination). If an exit code of "8 or higher" (indicating some copy failures or fatal errors) occurs, it is evaluated and notified as an error.

Q. Can I send external notifications when a backup completes or an error occurs?

A. Yes. By configuring a Slack Webhook URL or an ntfy.sh Topic Name in the "General Settings" tab, you can automatically send backup execution results and error notifications to your chat tools or smartphone.
