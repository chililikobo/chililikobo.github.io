Product Overview

"Turn hidden logs into reliable evidence."

LogonTime is an ultra-fast, lightweight command-line tool that parses Windows "System" event logs to extract user logon/logoff times and automatically calculate total active duration. It serves as an accurate, objective record for daily timesheet verification or remote work audit trails.

Flexible Time Range

Specify how many days of logs to inspect using command arguments (defaults to the past 30 days).

CSV & JSON Export

Beyond standard color-coded console output, easily export data via --csv or --json for script automation.

Multilingual Support (i18n)

Automatically switches output messages between English and Japanese according to your system locale.

.NET 10 Native AOT

Zero .NET runtime installation required. Operating as a single standalone executable with near-instant execution.

How to Use

01

Simple Run

Double-click LogonTime.exe to view the past 30 days of logs (window pauses automatically).

02

Custom Period

Specify the number of days as a command argument, such as LogonTime.exe 14.

03

Data Export

Append --csv or --json to redirect outputs into scripts or spreadsheet files.

Seamlessly integrates into shell scripts and pipe redirection without hanging.
