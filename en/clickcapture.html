Product Overview

"Everything you need, captured just by clicking."

ClickCapture is a lightweight utility that automatically captures screenshots in sync with your mouse left-clicks and drag operations. Designed as a modern, zero-install alternative to the deprecated Windows Problem Steps Recorder (PSR), it logs software setup flows and installer parameters effortlessly. Fully portable, it runs as a single executable directly from a USB drive on any machine—leaving zero trace and requiring no installation.

Click-Synced Capture

Automatically captures the active window or entire screen and saves sequentially numbered images on every click.

Rectangular Area Capture

Drag while holding down the Ctrl key to crop and capture any custom rectangular area on the fly.

Smart Duplicate Filtering

Intelligently skips saving if the screen remains identical, keeping your folders tidy and clutter-free.

Instant Hotkey Toggle

Press your assigned hotkey (default is F9; F8 also available) to instantly toggle capture ON or OFF.

Live Action Demo

Live capture: Images are auto-saved directly to the folder with visual click feedback.

Frequently Asked Questions (FAQ)

A. Check if the "Skip duplicate images" setting is enabled.
When turned on, the app skips saving if the screen area is identical to the previous capture to prevent redundant files. Try turning this setting OFF temporarily to verify normal capture behavior.

A. Administrator rights are required to monitor mouse click operations across all other applications (Global Hook).
Under Windows security architecture, standard applications cannot monitor input events occurring inside elevated windows without running elevated.

A. Yes, it is 100% safe. ClickCapture is a lightweight indie utility and does not include an expensive corporate EV code-signing certificate, causing Windows SmartScreen to display a standard caution dialog.
To run the application, simply click "More info" and select "Run anyway".

A. Because the application uses low-level Windows API hooks to detect clicks, certain antivirus heuristic engines can mistakenly identify it as a false positive.
If you run the app in a trusted environment, please add `ClickCapture.exe` to your security software's whitelist / exclusion list.

A. This can happen if your Windows display scaling (DPI scaling) is set to a non-100% ratio (e.g., 125% or 150%).
If you changed your display scale while the app was running, please restart ClickCapture to adapt to the new scaling ratio.

A. When "Copy captured image to clipboard" is active, clicking "Paste" immediately overwrites the clipboard with the new screenshot, canceling the file paste action.

To copy and paste files without interference, use one of the following methods:

  • Adjust Settings (Recommended): In the main window under "Advanced Settings", uncheck "Copy image to clipboard".
  • Use Keyboard Shortcut: Paste files using the Ctrl + V shortcut instead of left-clicking context menu items.
  • Temporary Pause: Press your hotkey (default is F9) to temporarily pause capture before pasting.
