Product Overview

"All essential metrics in the smallest possible space."

Simple Stats is a real-time system monitor that consolidates PC resource metrics and network parameters into a sleek, compact desktop widget. Featuring a high-contrast dark theme and optional "Always on Top" floating mode, it allows you to continuously keep an eye on system health without distracting from your core work.

Real-time 4-Resource Tracking

Continuously visualizes CPU, RAM, Disk, and Network load with intuitive circular gauges and live numerical metrics.

Instant Network Diagnostics

Quickly inspect your Hostname, IPv4 Address, Subnet Mask, Default Gateway, and primary DNS servers at a glance.

Smart Placement & Memory Savings

Auto-saves window desktop coordinates across restarts. Automatically trims memory usage when minimized.

Overload Warning Colors

Gauges automatically change to warning amber and red when resource usage exceeds 80%, providing early bottleneck alerts.
