Product Overview

"Essential PC and network telemetry at a glance—without getting in your way."

Simple Stats is an ultra-lightweight desktop telemetry HUD that keeps essential PC resource and network metrics cleanly visible without cluttering your workflow. Powered by pure Win32 / GDI+ rendering and .NET 10 NativeAOT, it ships as a ~3.0 MB single executable with a minimal memory footprint and near-zero CPU overhead.

Real-Time Monitoring & 60s Sparklines

Tracks Task Manager-aligned CPU, GPU usage/VRAM/temp (DXGI / D3DKMT across NVIDIA, AMD & Intel), RAM, physical Disk I/O (R/W), per-drive capacity bars, and Network throughput (▼/▲), smoothly shifting green → amber → red under load.

Dual Non-Intrusive Display Modes

Switch between Wallpaper Layer Mode (default: behind windows, survives Win+D) and Ghost Overlay Mode (click-through with mouse-proximity fade and Ctrl + Alt temporary unlock).

Fullscreen Auto-Pause

Automatically hides the HUD and suspends rendering/timers while a fullscreen game or presentation runs on the same monitor, restoring it on exit (stays visible on secondary monitors).

4 Themes, 3 Layouts & 3 Font Sizes

Choose Obsidian Glass, Pure Wallpaper, Cyber Cyan, or Frost Light across Standard, Minimal Zen, and Compact Mini layouts with Small / Medium / Large fonts.

Active NIC Tracking & 1-Click Copy

Auto-follows your active adapter with link speed, IPv4/CIDR, Gateway, and DNS. Left-click any host, CPU, GPU, drive, or network row to copy, or double-click the tray icon for a full snapshot.

NativeAOT & Zero-Registry Design

Single portable executable requiring no .NET runtime. Startup shortcut toggling (SimpleStats.lnk) writes zero registry keys and supports automatic EN/JA UI switching.

How to Use

01

Launch & Place

Run SimpleStats.exe from any folder and drag it anywhere (16px magnetic snapping) or pick a corner preset via right-click.

02

Right-Click to Customize

Right-click the HUD or tray icon to configure Display Mode, Theme, Layout, Font Size, Opacity, Refresh Interval (1s/2s/5s/60s), and Auto-Start.

03

1-Click Copy & Tray Controls

Left-click any host, CPU, GPU, drive, or network row to copy its value. Single-click the tray icon to show/hide, or double-click to copy the full system snapshot.

Settings are saved to window_settings.json and Auto-Start uses SimpleStats.lnk with zero Windows Registry writes (force UI language via --lang=en / --lang=ja).
