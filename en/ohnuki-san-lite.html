Product Description

"The essential specs you need, when you need them, at top speed."

Ohnuki-san Lite is a completely free Windows utility focused on displaying essential system specifications for everyday PC management and IT inventory auditing. Requiring no installation or registry modifications, simply run the executable from a USB drive or local disk to instantly view and export hardware components, BIOS serial numbers, and OS configuration into clean HTML and Markdown reports.

Zero Installation Required

Runs from a single executable without touching system registry settings. Carry it on a USB flash drive for instant diagnostics on any PC.

Intuitive Immediate UI

Automatically scans hardware and system parameters on launch, opening an organized HTML specification summary directly in your browser.

Markdown & HTML Export

In addition to interactive browser views, generate neat Markdown files that can be pasted directly into Jira, Notion, or internal wikis.

Free for Commercial Use

Free for personal, corporate, and educational use without feature limits or domain membership restrictions.
