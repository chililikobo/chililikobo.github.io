製品説明

「256pxから16pxへ。極小ドットへの凝縮をとことん追求。」

PinSharp ICO（ピンシャープ・アイコ）は、一般的な画像縮小ツールでアイコンを作成した際に起こりがちな「白い枠線がグレーに沈んでしまう」「黒いスリットが埋まって消える」「輪郭がボケてエッジを失う」といった現象を解決するために設計された専用ユーティリティです。

256×256pxの原画からわずか16×16px（面積比1/256）へと凝縮される過酷な縮小プロセスをとことん追求。細い境界線、文字、微小な隙間のコントラストを鮮明に保ち、タスクバーやタイトルバー、エクスプローラーの極小表示でも美しく際立つWindows標準のマルチサイズICOファイルを一瞬で書き出します。

極小特化の鮮鋭化設計

16×16や24×24などの極小化でも、細い枠線や文字、微小な隙間が背景に埋もれずパキッと浮かび上がります。

ドラッグ＆ドロップ全自動保存

画像をウィンドウにドロップするだけで即座に変換開始。面倒な保存ボタン操作なしで同名ICOを自動保存します。

Windows標準全11サイズ完全網羅

16, 20, 24, 32, 40, 48, 64, 72, 96, 128, 256pxに対応。All / Standard / Compact のプリセットも完備。

白フチ浮き（ハロー現象）ゼロ

一般的なシャープ化で発生しやすい輪郭の不自然な白浮きを、数学的な境界クランプにより原理的に防止します。

多彩な形式 ＆ 一括変換 Pro

PNGに加えJPEG、BMP、WebPにも対応。複数画像やフォルダごと（サブフォルダ再帰探索）の一括変換が可能です。

角丸・丸型マスク ＆ CLI自動化 Pro

モダンな角丸や円形アイコンへの自動切り抜きに対応。さらにコマンドライン（CLI）からのバッチ自動化も完備。

完全ポータブル・超高速Native AOT動作

PinSharp ICOは.NET 10のNative AOT技術でネイティブコンパイルされており、.NETランタイムの追加インストールは一切不要です。

展開したフォルダ内の「PinSharpICO.exe」を実行するだけでどのWindows PCでも即座に起動します。レジストリを変更せず、USBメモリから直接実行可能です。不要になった際もフォルダごと削除するだけで完全にアンインストールできます。

基本構文

PinSharpICO.exe <画像ファイルやフォルダのパス...> [オプション]

主なオプション

オプション 説明
-o, --output <パス> 出力先フォルダー（または単一ファイル時の出力 .ico パス）を指定
--subfolder 元画像と同じ階層に自動で icons/ フォルダーを作成して保存
-c, --shape <形状> 形状マスクを指定 (square: 四角, rounded: 角丸, circle: 丸型)
-s, --sizes <サイズ> 生成するサイズをカンマ区切りで指定 (例: 16,32,48,256)
-h, --help コマンドラインのヘルプを表示

実行例

# 1. 画像をアイコンにする（一番シンプル）
PinSharpICO.exe "my_icon.png"

# 2. 写真をおしゃれな角丸アイコンにする
PinSharpICO.exe "photo.jpg" --shape rounded

# 3. イラストを丸型アイコンにする
PinSharpICO.exe "avatar.webp" --shape circle

# 4. フォルダ内の全画像を角丸にして別のフォルダへ一括保存
PinSharpICO.exe "D:\Images" -o "D:\Icons" --shape rounded

# 5. 元画像と同じ階層の 'icons/' フォルダへ自動保存
PinSharpICO.exe "D:\Images" --subfolder

# 6. 生成するサイズを限定して高速変換
PinSharpICO.exe "icon.png" -s 16,32,48,256
